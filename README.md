## 簡介

病歷整理器是一款用於整理和輸出病歷資料的網頁應用程式，專為放射腫瘤科設計。可於瀏覽器中離線使用，亦可部署於 GitHub Pages。

---

## 功能特色

- **密碼保護**：開啟時需輸入密碼（預設 RTO）
- **7 個分頁**：病人、病摘、檢驗、病理、影像、整理結果、Prompt（開啟後直接從「病人」開始）
- **10 個 Prompt 範本**：編輯/儲存/命名分開操作
- **預設範本載入**：密碼保護，可選擇多組預設範本
- **病人資料管理**：姓名、年齡、病歷號、ECOG、衰弱量表
- **檢驗資料**：自由輸入 + 腫瘤指數追蹤
- **報告管理**：病理報告與影像報告
- **AI 整理功能**：支援 OpenAI / Claude API；按「AI 整理」自動整合各分頁最新資料，不需先產生預覽
- **整理結果頁**：AI 結果與原始整合內容同頁，各自可複製／匯出；未設定 API Key 時可複製原始內容貼到外部 AI
- **匯出功能**：支援 TXT、HTML、PDF 格式（整理結果頁的「匯出」選單）
- **連續輸入**：病理／影像「儲存+繼續」（Ctrl+Enter），列表顯示兩行摘要、整列可點
- **自動儲存**：輸入中即時儲存，右上角顯示狀態
- **新病人**：一鍵清除目前病人資料與 AI 結果，範本保留
- **個資遮蔽**：預設開啟，預覽及匯出時自動遮蔽病人姓名
